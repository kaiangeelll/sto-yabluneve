# Інструкції для агентів, що продовжують проєкт

## Контекст

Це сайт `СТО Евакуатор`, адреса: вул. Яблунева, 20, Нове, Київська область. Інтерфейс має бути українською. Користувач може писати російською або з помилками, але тексти сайту лишаються українськими, якщо він прямо не попросить інше.

## Дизайн, який треба зберігати

- Теплий світлий фон, лаймові акценти, темно-зелений текст.
- Великі округлі картки, радіус приблизно 16–30 px.
- Легка анімація під час наведення: підняття 2–7 px, м’яка тінь або лаймове світіння.
- Не повертати помаранчеве велике коло на головний екран.
- Спершу перевіряти вигляд на телефоні; мобільні стилі у `mobile.css`.

## Функціональні правила

- Натискання на картку послуги має відкривати запис із уже обраною послугою.
- Коментар до заявки необов’язковий.
- Не дозволяти два активні записи на одну дату й годину.
- Вихідні та окремі недоступні години має задавати адміністратор.
- Не показувати кнопки WhatsApp/Viber/Telegram, доки власник не вкаже реальний контакт.
- Не створювати фальшиві відгуки, фальшиві ціни, профілі або контактні дані.

## Безпека

- Поточний адмін-вхід є лише демо: `admin` / `sto-2026`. Не називайте його безпечним.
- Для production перенесіть авторизацію, ролі, записи й відгуки на серверну платформу.
- Ніколи не кладіть SMS, Telegram, email, Firebase або платіжні ключі в браузерний код.
- Будь-яка відправка SMS, email або повідомлень має відбуватися тільки на сервері після валідації заявки.

## Перед будь-якою зміною

1. Прочитайте `README.md`, цей файл і `BACKEND.md`, якщо зміна стосується даних або акаунтів.
2. Не перезаписуйте налаштування користувача у `localStorage` без міграції схеми.
3. Додавайте нові UI-стилі окремим тематичним CSS-файлом або акуратно доповнюйте наявний.
4. Перевіряйте синтаксис кожного зміненого JS-файлу через `node --check`.
5. Для фактичного деплою виконуйте `DEPLOYMENT.md` і не публікуйте без дозволу користувача.
