# Публікація сайту

## GitHub Pages

Для короткої адреси `https://kaiangeelll.github.io/` репозиторій має називатися рівно `kaiangeelll.github.io` і бути публічним.

Якщо репозиторій називається `sto-kyiv`, адреса буде:

`https://kaiangeelll.github.io/sto-kyiv/`

В URL не можна залишити тільки `sto-kyiv/`: будь-яка вебадреса обов’язково містить домен. Для короткої власної адреси потрібен окремий домен, наприклад `sto-kyiv.ua`.

## Публікація вручну

1. Увійдіть у GitHub CLI: `gh auth login -h github.com`.
2. Створіть публічний репозиторій потрібної назви.
3. Завантажте в його корінь увесь вміст `outputs/sto-evacuator-site/`.
4. У GitHub відкрийте **Settings → Pages**.
5. Виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`.
6. Дочекайтеся появи адреси Pages.

## Перед публікацією

- перевірити телефон, адресу та посилання Google Maps;
- додати реальні профілі WhatsApp/Viber/Telegram через адмін-панель;
- не публікувати тестові паролі як production-рішення;
- перевірити сторінку на телефоні;
- після отримання домену додати `CNAME` та оновити SEO-канонічну адресу.
