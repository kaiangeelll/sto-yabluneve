# СТО Евакуатор — сайт автосервісу

Статичний україномовний сайт для автосервісу в Новому, Київська область.

## Швидкий старт

Відкрийте `outputs/sto-evacuator-site/index.html` у браузері. Це статичний сайт без збірки та залежностей.

## Що вже працює

- адаптивна головна сторінка, послуги, контакти, карта й фото;
- запис на конкретну послугу з календарем на наступні 7 місяців;
- блокування зайнятих годин, вихідних та закритих дат у демо-режимі;
- відгуки з оцінкою;
- особистий кабінет і демонстраційний кабінет адміністратора;
- керування послугами, цінами, графіком, месенджерами та заявками;
- SEO-мета-теги та JSON-LD `AutoRepair`.

## Важливе обмеження

Зараз дані зберігаються у `localStorage` браузера. Це демо, а не спільна база: різні телефони не бачать одне одного. SMS, email, Telegram/Viber/WhatsApp-нотифікації та захищений вхід потребують бекенду. Деталі у [BACKEND.md](BACKEND.md).

## Внесення змін

1. Спершу прочитайте [AGENTS.md](AGENTS.md).
2. Для контентних правок відкрийте адмін-панель у демо або відредагуйте `app3.js`.
3. Не додавайте секрети, токени або паролі у JavaScript чи HTML.
4. Після зміни JavaScript перевірте: `node --check outputs/sto-evacuator-site/app3.js`.
5. Перед публікацією дотримуйтеся [DEPLOYMENT.md](DEPLOYMENT.md).

## Контакти, які потребують підтвердження власником

Кнопки WhatsApp/Viber/Telegram показуються лише після заповнення посилань у адмін-панелі. Не вигадуйте посилання, профілі чи номери месенджерів.
